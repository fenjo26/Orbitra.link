# Источники трафика и партнёрские сети

Два справочника, которые настраивают «края» воронки: **источник трафика** описывает, какие параметры приходят в ссылку кампании и куда отправлять конверсии обратно; **партнёрская сеть** — какие параметры дописать к офферу и куда сеть шлёт постбек.

## Источники трафика

Раздел **Источники** в верхнем меню.

### Шаблоны

Около 200 шаблонов: 196 из выгрузки шаблонов Keitaro (`data/keitaro_traffic_sources.json`) плюс встроенные (Facebook, Google Ads, TikTok, Snapchat, VK, Яндекс и др.). Шаблон заполняет параметры и постбек источника. Можно создать и «кастомный источник» без шаблона.

> Шаблоны — сгенерированные данные. Их нельзя править руками: ошибка в одном макросе выглядит в интерфейсе нормально, но клик приходит без `external_id`, и ни один постбек потом не находит клик. Обновляются скриптом `cli/generate_keitaro_templates.py` из экспортов Keitaro, проверка — `php tests/keitaro_templates_test.php`.

### Параметры

Каждый параметр — тройка:

| Поле | Пример | Смысл |
|---|---|---|
| Псевдоним | `ad_id` | Имя, под которым значение хранится в клике (`clicks.parameters_json`) и доступно как `{ad_id}` |
| Параметр | `ad_id` | Имя параметра в URL кампании |
| Макрос источника | `{{ad.id}}` | Что подставить в ссылку в рекламном кабинете |

При выборе источника в кампании эти параметры автоматически добавляются к её URL. Именно они дают импорту расходов ID для привязки ([Расходы](costs.md)) и фильтру «Параметр URL» — значения.

### Постбек в источник

`postback_url` и статусы, которые отправлять. Когда кампании назначают такой источник, его постбек попадает на вкладку **S2S Postbacks** кампании — см. [Постбеки и конверсии](postbacks.md#исходящие-s2s-постбеки-в-источник-трафика).

### Проверка URL

У источника можно указать URL для проверки доступности. Проверить все разом — кнопка в списке, команда бота `/checksources` или крон:

```
0,30 * * * * php /var/www/orbitra/check_sources_cron.php
```

## Партнёрские сети

Раздел **Партнерки**.

### Шаблоны

Около 440 шаблонов: 395 из выгрузки Keitaro (`data/keitaro_affiliate_networks.json`) плюс встроенные. Шаблон даёт:

- **Postback URL** для кабинета сети (глобальный постбек) — `https://ваш-домен/<postback_key>/postback?subid=…&status=…&payout=…`;
- **Параметры оффера** — что дописать к URL каждого оффера этой сети.

### Параметры оффера

Например `&subid={subid}&campaign={sub_id_1}`. Они добавляются к URL оффера в момент клика, а не сохраняются в оффер: правка сети сразу действует на все её офферы. Параметр, уже записанный в URL оффера, имеет приоритет — ручной `subid={subid}` не задвоится. Поддерживаются и суффиксы пути вида `/{subid}`. Полные правила — [Affiliate network offer parameters](affiliate-network-parameters.md) (на английском).

Доступные макросы: `{subid}` / `{clickid}` (ID клика), `{ip}`, `{country}`, `{device}`, `{referer}`, `{keyword}`, `{cost}`, `{external_id}`, `{creative_id}`, `{ad_campaign_id}`, `{offer_id}` и любые параметры клика (`{sub_id_N}`, `{ad_id}`…). Макрос, для которого у клика нет значения, превращается в пустую строку.

## LeadForge

**LeadForge** (меню ⚙) — отдельный инструмент: собирает локальный оффер-лендинг из скачанной страницы и отправляет лиды в CPA-сеть через сгенерированный `order.php`. Его список сетей — это исходящие адаптеры отправки лида, а не справочник «Партнерки». Подробнее — в разделе LeadForge [Лендингов](landing-pages.md#leadforge-20-landing-analyzer-js-validation--multi-network-bridge).
