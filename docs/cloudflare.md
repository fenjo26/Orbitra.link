# Cloudflare — управление DNS и SSL доменов

Интеграция подключает трекер к Cloudflare через API: домены, которые вы
паркуете в Orbitra, получают A-запись на сервер трекера **автоматически**,
а при включённом прокси (оранжевое облако) SSL выдаётся краем Cloudflare
мгновенно — без certbot и ожидания валидации.

Настройка: **Интеграции → Cloudflare** (группа «Домены и SSL»).

## 1. Создание API-токена

1. Cloudflare → **My Profile → API Tokens → Create Token**.
2. Шаблон **«Edit zone DNS»** → *Use template*.
3. В Permissions нажмите **Add more** и добавьте **Zone · Zone · Edit**
   (нужно для смены SSL-режима зоны; без него DNS тоже будет работать).
4. **Zone Resources: Include → All zones**.
5. Continue to summary → **Create Token** → скопируйте токен.

## 2. Подключение в Orbitra

- **API Token** — токен из шага 1 (проверяется при сохранении).
- **IP сервера** — куда указывать A-записи. По умолчанию определяется
  автоматически; можно задать вручную.
- **SSL режим зоны** — `Flexible` (SSL сразу, CF ходит на сервер по HTTP),
  `Full` (нужен сертификат на сервере, напр. от Let's Encrypt), `Strict`.
- **Cloudflare Proxy** — оранжевое облако. Включён = SSL от CF + домен
  выходит из очереди certbot (`ssl_status = cloudflare` в списке доменов).

## 3. Как это работает

- **Парковка домена**: при добавлении домена (в т.ч. поддомена) трекер ищет
  зону в аккаунте CF — `sub.example.com` найдёт зону `example.com` — и
  прописывает/обновляет одну A-запись `sub.example.com → IP сервера`.
  Лишние A/AAAA-записи этого имени удаляются, чтобы не перебивали нашу
  (семантика Keitaro: «остаются только нужные записи»).
- **Зоны нет в аккаунте** — домен живёт как раньше: ручная DNS + Let's Encrypt.
- **Перенос трекера на новый сервер**: измените IP сервера в интеграции и
  нажмите **«Перепарковать все домены»** — все A-записи CF-доменов укажут на
  новый IP.
- **Поддомены**: создавайте их как обычные домены в разделе «Домены» — записи
  появятся в CF автоматически (зона родителя должна быть в аккаунте).

## 4. Что хранится и что вызывает Cloudflare

- Токен лежит в `settings` (`cf_api_token`) — так же, как токены других
  интеграций.
- Вызовы API: `/user/tokens/verify`, `/zones`, `/zones/{id}/dns_records`
  (GET/POST/PUT/DELETE), `/zones/{id}/settings/ssl`.
- Домены под управлением помечены `ssl_status = 'cloudflare'` — certbot их
  не трогает, в списке доменов у них иконка облака.
