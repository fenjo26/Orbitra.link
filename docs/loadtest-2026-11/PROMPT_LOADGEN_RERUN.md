# Задача: повторный прогон после двух правок на трекере

На трекере применены две экспериментальные правки: постоянное соединение с SQLite и `worker_connections 4096` в nginx (подробности у агента трекера в `/root/loadtest/EXPERIMENT.md`). Повтори тест теми же скриптами и с той же методикой. Префиксы прогонов: `x` вместо `u`/`r` (например `xu1`, `xr1`), чтобы не смешать их с первыми результатами.

1. `unique`: лестница 20 → 480. Если 480 пройдена, продолжи 640 и 800 (вне методики статьи, отметь это).
2. `repeat` (пул 10 000): лестница 20 → 480.
3. Максимальную пройденную ступень каждого профиля повтори ещё 2 раза на чистой базе.
4. `repeat-tight` не повторяй.

Результат положи в `/root/lt/results_x/` в том же формате: `summary.md` с теми же таблицами, плюс отдельная таблица «до → после» по ступеням 20/80/160/320/480 (p50, p99, ошибки, CPU трекера). Архив: `/root/lt/results_x.tar.gz`. Без выводов, только числа.
