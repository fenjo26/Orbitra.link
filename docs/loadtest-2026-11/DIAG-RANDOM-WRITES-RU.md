
## 6. Замер шага-1 (профиль CPA.RIP uniques, дополнено в тот же день)

Каждый клик — НОВЫЙ случайный публичный IP (без повторов), UA из пула 41,
база 2М строк с РАВНОМЕРНО СЛУЧАЙНЫМИ префилленными IP (прошлые шаблоны
гоняли пул 65k — занижали ip-индексы; эта база заполняет всё пространство —
честная форма стенда). Страниц/клик: базовая 2.11; **решённый вариант
(uuid7 + без ip_created) 1.82–1.83** (главный вклад ip_ua 0.82); вариант
«b + INTEGER-хэш(ip|ua) вместо TEXT ip_ua» — стационарно ~1.3 (хэш-индекс
0.47/клик, размер 16.3k страниц против 26.5k, −39%). Итог > 1.3 →
предложение по ужатию ip_ua (шаг 2, не реализовано): колонка
`ipua_hash = crc32(ip.'|'.user_agent)`, индекс `(ipua_hash, created_at)`,
пробы `WHERE ipua_hash = ? AND created_at >= ?` + точная проверка ip/ua в
PHP (паттерн уже используется legacy-веткой проб; коллизия crc32 стоит
лишнего кандидата, не неверного вердикта); миграция — батчами спул-воркера
по рецепту миграции 55.
