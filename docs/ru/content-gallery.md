# Галерея контента

Галерея — общая медиа-библиотека трекера: папки, загрузка, поиск и пикер
`MediaPicker`, через который иконки и скриншоты выбираются в редакторах PWA,
лендингов и офферов. Файлы лежат на вашем сервере (`uploads/media/`), никакого
внешнего хранилища.

---

## 1. Страница «Галерея»

- **Папки** — плитки папок над сеткой файлов; клик открывает папку. Удаление
  папки файлы не теряет: они переезжают в корень.
- **Загрузка** — кнопка или drag-and-drop. Файл переименовывается сервером
  (hash-префикс + суффикс), оригинальное имя сохраняется в метаданных.
- **Фильтры** — статус, пользователь, поиск по имени.
- **Массовые операции** — переместить в папку, удалить.
- **Удаление мягкое** (`is_active=0`): файл исчезает из пикера, но страницы,
  которые уже выбрали это изображение, продолжают его показывать.

### Ограничения

| Параметр | Значение |
|---|---|
| Форматы | webp, jpg, jpeg, png, gif (SVG запрещён — XSS) |
| Размер | до 10 МБ |
| Проверка | `getimagesize()` + MIME `image/*` — переименованный файл не пройдёт |

## 2. MediaPicker в редакторах

Кнопки выбора изображений в **PwaEditor** (иконка 512×512, скриншоты),
**LandingEditor** и **OfferEditor** открывают общий пикер: сетка ассетов
Галереи, вкладка загрузки, обновление списка при каждом открытии.

### sizeContract: требования к размеру

Пикеру можно задать контракт размера, например иконка PWA —
`512×512, crop: true`:

- плитки помечаются: **точное совпадение** / **можно кадрировать** / **мало**;
- при выборе «крупного» изображения открывается кадрирование — рамка с
  фиксированным соотношением сторон; результат сохраняется как **новый ассет
  библиотеки** ровно контрактного размера (PNG), оригинал остаётся нетронутым;
- изображения меньше контрактного выбрать нельзя.

Без контракта (скриншоты) выбирается любое изображение как есть.

### Где что используется

- **PwaEditor**: иконка приложения (512×512 с кадрированием), скриншоты
  витрины; из них же собирается манифест (192/512 + maskable из одного
  источника);
- **LandingEditor / OfferEditor**: превью и ассеты лендингов/офферов.
