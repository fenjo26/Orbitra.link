# Гайд для новичков: с чего начать

Впервые в Orbitra или вообще в трекерах? Этот раздел проводит по трекеру так, как вы будете им пользоваться на самом деле — экран за экраном, со скриншотами. В каждом гайде есть часть «Что это» простыми словами и часть «Как настроить» по шагам.

Справочные страницы ([Кампании и потоки](campaigns.md), [Постбеки](postbacks.md) и остальные) по-прежнему описывают каждую опцию и все тонкости. Гайды ссылаются на них, когда нужно глубже.

## Что делает трекер — на одной картинке

Трекер стоит между вашей рекламой и страницей рекламодателя. Каждый посетитель проходит через него, поэтому трекер может решить, куда его отправить, и запомнить, что произошло.

```
 Реклама (Facebook, TikTok, пуши…)
        │  посетитель кликает по объявлению
        ▼
 Ссылка кампании  https://go.example.com/5i5pvic4
        │  Orbitra записывает клик и присваивает ему ID (subid)
        ▼
 Потоки — правила: «Германия + телефон → оффер A», «боты → 404», «все остальные → лендинг»
        │
        ├──► Лендинг (необязательно) ──► Оффер
        └──► Оффер (страница рекламодателя в партнёрке)
                         │  посетитель покупает / регистрируется
                         ▼
 Партнёрка ── постбек с subid ──► Orbitra отмечает клик как конверсию
                         │
                         ▼
 Отчёты: клики, конверсии, расход, доход, прибыль, ROI — по кампаниям, странам, креативам…
```

## Слова, которые будут встречаться

| Слово | Что это в Orbitra |
|---|---|
| **Кампания** | Одна трекинговая ссылка, которую вы ставите в рекламу, плюс правила (потоки) за ней |
| **Поток** | Правило внутри кампании: кого он берёт (фильтры) и куда отправляет (оффер, лендинг, safe page, 404…) |
| **Оффер** | Страница рекламодателя, за действия на которой вам платят. Обычно ссылка из партнёрки |
| **Лендинг (прелендинг)** | Ваша страница перед оффером, которая «прогревает» посетителя |
| **Партнёрка (партнёрская сеть)** | Партнёр, который платит (Dr.Cash, Leadbit…). Присылает конверсии постбеком |
| **Источник трафика** | Откуда приходят посетители (Facebook, TikTok, Google, пуш-сети). Задаёт, какие ID рекламы попадут в ссылку |
| **Постбек** | Уведомление «сервер → сервер»: «клик X сконвертился, статус sale, выплата 30» |
| **Click ID / subid** | Уникальный ID, который Orbitra даёт каждому клику. Партнёрка должна вернуть его в постбеке |

Все сокращения (CPA, RevShare, FTD, EPC…) — в [Словаре](glossary.md), а каждая цифра в отчётах объяснена в [Шпаргалке по метрикам](guide-metrics.md).
