# Библиотека креативов

Вкладка «Креативы» в Галерее контента отвечает на один вопрос: **какие креативы реально зарабатывают**. Она вырастает из существующей галереи: файлы, синхронизированные с площадок (картинки и видео Facebook, обложки TikTok), лежат рядом с вашими загрузками, у каждого креатива — расход/доход/ROI, а вручную загруженная заготовка получает метрики в тот момент, когда объявление начинает её крутить.

## Как попадают данные

Ничего не настраивается руками. Цепочка:

1. **Синк расхода** (крон агрегатора или «Синхронизировать») тянет строки расхода из Facebook/TikTok. Каждая строка теперь несёт имена ad/adset/кампании и счётчики площадки (показы/клики — `cost_records.impressions`, `platform_clicks`) и апсертит их в `ad_entities`.
2. **Метаданные креативов** (`core/CreativeSync.php`, троттл — один проход в 3 часа на подключение) спрашивает площадку, что в этих объявлениях: хэш картинки / id видео / текст объявления. Связки — в `creative_usages`, задачи на скачивание — в `creative_fetch_queue`.
3. **Воркер файлов** (`cli/creative_fetch_cron.php`, крон install.sh каждые 5 минут) скачивает сами файлы: оригиналы Facebook (`/act_X/adimages` по хэшу, видео с источником и обложкой), обложки и превью TikTok (`/file/video/ad/info/`, `/file/image/ad/info/`). Дедуп точный по sha256; почти-дубликаты — по 64-битному dHash с порогом Хэмминга ≤6 — это и есть связка «заготовка вышла в работу»: ваш ручной файл привязывается к платформенной копии, а не создаёт дубль.
4. **Дневной агрегат** (`core/CreativeStats.php::rebuildWindow`) пересобирает `creative_daily` после каждого синка расхода: расход (с комиссией агентства), показы, клики площадки, клики/визиты трекера, инстоллы, реги, FTD и доход — трекерные метрики ложатся в дни таймзоны кабинета через индексированную колонку `clicks.ad_ref`.

Воркер проверяет загрузки по сигнатуре (mp4 `ftyp` / webm EBML для видео, `getimagesize` для картинок), держит лимиты объёма (10 МБ картинки, 100 МБ видео) обрывом передачи, ходит через прокси подключения. Баннер на вкладке скажет, если файлы в очереди, а воркер не запускался.

## Вкладка

- **Фильтры**: период (по умолчанию 7 дней), платформа, формат, тег, поиск, «только активные» (креативы, чьи объявления ещё крутятся), сортировка по расходу/доходу/ROI/кликам.
- **KPI-карточки** по уникальным ассетам — карусель из трёх картинок это один креатив, расход дня делится на троих поровну.
- **ROI без дохода — прочерк, а не −100%**: пустой креатив не есть сгоревший. Цвета: зелёный ≥ 30%, янтарный 0–30%, красный ниже нуля.
- **Карточка креатива**: серия по дням (столбцы расхода, отметки ROI), объявления с статусами и расходом (путь *Кабинет › Кампания › Адсет*), текст объявления, семья похожих, теги, скачивание.
- Теги свободные (`оффер, гео, подход, креатор`) — отчёт по тегу отвечает «какой подход лучше».

## Где креативы ещё всплывают

- **Отчёты кампаний** получают группировку «Креатив» (имя файла вместо голого id) и превью-миниатюру в строках объявлений.
- **Редактор кампании** — вкладка «Креативы»: что несло трафик в эту кампанию за 7 дней и их ROI по трекеру.
- **Telegram-дайджест** — топ-3 и антитоп-3 креатива дня плюс алерт «выгорание»: ROI или CTR площадки упали сильнее порога (по умолчанию −50%) за последние 7 дней против предыдущих семи при расходе выше минимума ($50). Пороги: `telegram_creative_burnout_drop_pct`, `telegram_creative_burnout_min_spend`.
- **Расширение Ads Manager** показывает CREATIVE ROI (за всё время) рядом с дневными цифрами объявления.
- **MCP**: `orbitra_creatives_top`, `orbitra_creative_detail`.
- Платформенные файлы доступны в **MediaPicker** как постеры для PWA/лендингов.

## Баннер «доход не привязан»

Баннер над отчётом («К объявлениям привязан 62% дохода») считает `action=revenue_attribution_health`: доход считается привязанным, когда хоть один ad-параметр клика несёт настоящий id площадки — нераскрытый макрос `__CID__` / `{{ad.id}}` считается пропуском, тем же правилом, что диагностика импорта расхода. Кнопка «Исправить» открывает редактор источника с подсвеченной вкладкой параметров.

## Заметки

- Видеофайлы TikTok не скачиваются (нужны отдельные права на ассеты): хранится обложка, метрики у креатива всё равно полные.
- Вторую очередь (AI-разбор текста, автотеги) сознательно не строили.
