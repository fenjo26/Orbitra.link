# Миграция из Binom

Orbitra подтягивает настройки напрямую с трекера Binom v2 через его Public API — партнёрские сети, офферы, лендинги, домены, источники трафика и кампании со всей структурой (пути, правила, веса). Статистика кликов не переносится: это старт с чистого листа.

## Что переносится

| Binom | Orbitra | Что сохраняется |
|---|---|---|
| Партнёрские сети | Партнёрские сети | Название (флаг архивации) |
| Офферы | Офферы | URL, выплата, авторазвыплата, гео, сеть |
| Лендинги | Лендинги | Название, URL |
| Домены | Домены | Хост, флаг HTTPS |
| Источники трафика | Источники | Название, postback URL, макросы токенов |
| Группы кампаний | Группы кампаний | Название |
| Кампании | Кампании | Название, **ключ трекинга (как Click API token)**, модель и сумма расходов, режим ротации, домен, группа, источник, удалённое состояние |
| `defaultPaths` | Потоки (fallback) | Позиция, вес, лендинги + офферы с весами |
| `rules` | Потоки (обычные, с фильтрами) | Критерии `country` / `language` / `device_type` → фильтры, `is` / `is_not` → разрешить / запретить |
| Офферы с прямым URL | Офферы | Создаются как настоящие офферы (`[Binom] direct URL offer`), веса сохраняются |

Не переносится: клики и конверсии (API Binom не отдаёт их построчно), постбеки кампаний, режимы SMART скрытия реферера (импортируются с обычным редиректом — см. отчёт). Критерии правил без эквивалента в Orbitra попадают в отчёт импорта счётчиком — ничего не выбрасывается молча. Правило с `markAsBot` импортируется как обычный поток с пометкой в отчёте.

## 1. Получите API-ключ

В панели Binom: **Settings → User** — у каждого пользователя свой ключ. Для импорта достаточно прав на чтение; Binom рекомендует отдельного ограниченного пользователя для стороннего доступа — мы тоже.

Адрес трекера и ключ вводятся при каждом импорте и не сохраняются на стороне Orbitra.

## 2. Импорт

Админ → Миграции → **Импорт из Binom (API)**:

1. Введите адрес трекера (например, `https://track.example.com`) и API-ключ.
2. Нажмите **Проверить соединение** — Orbitra покажет таймзону и сколько сетей, офферов, лендингов, доменов, источников и кампаний видно.
3. Выберите, что переносить. Кампании забирают с собой пути и правила в виде потоков; предпросмотр прогоняет всю выкачку в режиме dry-run и ничего не пишет.
4. Нажмите **Импортировать**.

Повторный импорт обновляет, а не дублирует: сущности сопоставляются по их id из Binom (колонки `binom_id`) и по натуральным ключам (URL оффера, URL лендинга, имя домена, токен кампании).

## Замечания по маппингу

- **Ротация.** `distributionType` `NORMAL` / `SMART_PATHS*` → ротация по весам; `TOP_TO_BOTTOM` / `FIX_ON_PATH*` → по позициям.
- **Порядок.** Binom применяет правила сначала, потом пути по умолчанию; потоки Orbitra получают тот же порядок (правила на ранних позициях, пути по умолчанию — в конец как fallback).
- **Алиасы.** У Binom нет алиасов кампаний, Orbitra генерирует их из названий и следит за уникальностью.
- **Токены.** Ключ кампании Binom становится токеном кампании Orbitra — постбеки, построенные на старом ключе, продолжат резолвиться.
