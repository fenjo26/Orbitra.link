# Возможности Orbitra

Короткий обзор с переходами на подробные страницы. История изменений по версиям — в [CHANGELOG](../CHANGELOG.md).

## Трафик

- **Кампании и потоки** — перехватывающие, обычные и замыкающие потоки, ротация по позиции или весу, 14 типов фильтров (страна, устройство, ОС, браузер, язык с регионами, бот, IP, ISP, тип соединения, реферер, ключевое слово, параметр URL, день недели, время), логика И / ИЛИ. → [Кампании и потоки](campaigns.md)
- **Схемы** — прямой переход на оффер, лендинг + оффер, действие (404, текст, HTML, другая кампания), клоакинг.
- **Автооптимизация ротации** — веса офферов и лендингов пересчитываются по продажам, CR, EPV, EPC или ROI.
- **Тестовые ссылки** — настоящая маршрутизация без записи клика, подмена страны `_geo`, трассировка `_dbg`.
- **Клоакинг** — дата-центры, VPN и прокси, списки ботов, эвристики User-Agent, проверка JavaScript, режим «чистых — в следующий поток». → [Клоакинг](cloaking.md)
- **Лендинги** — локальные (ZIP и встроенный редактор), внешние, preload, action, PHP; макрос `{offer}`, передача выбора на лендинге в `sub_id_N`, время на странице. → [Лендинги](landing-pages.md), [Tracking Client (PHP)](tracking-client-php.md)
- **PWA-лендинги и Web Push** — конструктор приложения в стиле магазина с богатой нативной шторкой установки (ваши скриншоты в промпте Chrome, живая проверка готовности), воронка экранов, локализованная офлайн-страница и подсказка для встроенных браузеров, своя база подписчиков и рассылки на своих VAPID-ключах с трекингом кликов, CTR по сообщениям, гео/языковым таргетингом, баннерами в уведомлениях и отпиской в один тап. → [PWA и Web Push](pwa-push.md), [PWA Funnel](pwa-funnel.md), [Галерея контента](content-gallery.md)
- **Конверсионные попапы** — собственный попап каждой кампании с кнопкой оффера (редактор → вкладка «Попап»): шаблон, текст и сумма, картинка, когда показывать; живое превью и подсказка готовности, статистика воронки попапа и измерение «дизайн × текст»; Настройки → Плагины — обзор и шаблон для новых попапов. → [Конверсионные попапы](conversion-popups.md)
- **Превью ссылки для соцсетей** — ботам превью из мессенджеров достаётся ваша og:*-карточка вместо клик-маршрута; люди идут как обычно. → [Кампании и потоки](campaigns.md#превью-ссылки-для-соцсетей)
- **Click API** — токены кампаний, совместимые с Keitaro, `click.php`, Click API v3, `kclient.php`.

## Конверсии и деньги

- **Постбеки** — обучение статусов, встроенные алиасы, свои типы конверсий, конвертация валют, журнал входящих. → [Постбеки и конверсии](postbacks.md)
- **S2S в источник** — очередь с повторами, тестер, повторная отправка пропущенного, автоподстановка постбека источника.
- **Conversions API** — Meta и TikTok, с надёжной доставкой и подтверждением. → [Facebook / Meta](facebook.md)
- **Расходы** — Facebook, TikTok (в том числе без приложения разработчика, через MCP), Google Ads с MCC, Dolphin / Fbtool, диагностика несопоставленного расхода. → [Расходы](costs.md)
- **Push и pop сети** — импорт расхода из AdMaven, PropellerAds, Kadam, Galaxion, HilltopAds, Adsterra и Clickadu, по кампании и — где сеть отдаёт — по зоне (сайту). → [Push и pop сети](push-pop-networks.md)
- **Zone Killer** — правила на кампании, которые подсвечивают (а в режиме auto и блокируют через API сети) зоны, сжигающие деньги; dry-run по умолчанию, журнал блокировок. → [Push и pop сети](push-pop-networks.md#zone-killer)
- **Агрегатор доходов** — забор дохода из кабинетов партнёрок без постбеков.

## Аналитика

- Дашборд, список кампаний с настраиваемыми колонками, конструктор отчётов с ~40 измерениями, тренды, когорты. → [Отчёты, логи и метрики](reports.md)
- Лог кликов в стиле Keitaro: колонки и фильтры по любому параметру, CSV до 100 000 строк, карточка клика с полной детализацией устройства и реальным направлением.
- Честная воронка лендинга: реальные переходы, время до оффера, время на странице, «возможные боты».

## Добавления v1.7.1

- **Таймзона TikTok**: расход ложится по календарному дню кабинета (было UTC); OAuth подхватывает таймзону/валюту автоматически; `aggregator_cron.php --rematch --days=30` переразлаживает историю.
- **Агентства**: комиссия арендодателя вписывается в каждый импорт — ROI учитывает её с первого синка, история не переписывается.
- **Имена и метрики площадки в отчётах**: имена вместо id, чипы статусов, Показы / клики площадки / CPM / CTR / **Потеря кликов** (1 − посетители трекера / клики площадки).
- **Библиотека креативов**: вкладка «Креативы» в галерее — файлы с площадок с расходом/доходом/ROI, dHash-семьи (ручная заготовка получает метрики, когда объявление начинает её крутить), теги, серии по дням, группировка в отчётах, топ/антитоп в Telegram-дайджесте с алертами выгорания, MCP-инструменты.
- **Автовыход из in-app браузера** (рендерер v19+): intent:// / x-safari с продолжением того же клика и процентом успешных выходов.
- **Пуш-инджажмент**: честные события «показано» с устройства, атрибуция конверсий по пушам (окно, последний клик побеждает), макросы {offer.value} из таблицы оффера по странам, отправка по местному времени с тихими часами.
- **Чистилка комментариев FB**: наборы правил (стоп-слова в режиме целого слова, регулярки админа, ссылки/контакты/эмодзи/повторы/длина), пробный режим по умолчанию, скрытие по умолчанию, журнал с возвратом, автопауза по лимитам.
- **Внешние PWA-конструкторы** (PWA.Group / TSL.app / свой) как взвешенные цели потока с возвратом `/eflow/<кампания>` и постбэками с `{eid}`.
- **Telegram-каналы как офферы** на отдельных ботах воронки (не админском): ссылки `t.me/<бот воронки>?start=<subid>`, инвайты с заявкой, автоодобрение в пределах окна оффера, конверсии `tg_join`, входящие постбэки по `tg_user_id` + `channel_id`.
- **Отбивка конверсий в каналы**: правила через админского бота — выбранный чат, статусы и кампании, HTML-шаблон с названиями объявлений, тест и журнал.


## Добавления v1.7.3

- **Веб-пуши оператору**: панель устанавливается как приложение (кнопка «Установить» в навбаре / подсказка для iOS); каждый пользователь подписывает свои устройства и получает пуши о конверсиях (фильтры по статусам/кампаниям) и итоги дня/недели/месяца в локальное время профиля. → [PWA и веб-пуши](pwa-push.md)
- **Раздел «Уведомления»**: пуш (личный) + Telegram (админ: чаты с переключателями, коды привязки, расписание, правила каналов) в одном месте; входы из меню аватара/шестерёнки, Профиля и страницы Push; deep-link'и `?tab=notifications&sub=…`.
- **Итоги недели и месяца в Telegram**: последняя полная неделя (пн–вс) и месяц, даты в заголовке, команды `/weekly` `/monthly` на семи языках, доставка один раз за окно с догоном.
- **Честные дайджесты**: окна в часовом поясе читателя (пуши — профиль; Telegram — первый админ), клики белых страниц клоак исключены, уникальные метки на каждую конверсию, переход по тапу в конверсии/дашборд.

## Добавления v1.7.4

- **Надёжность доставки пушей**: отправитель операторских пушей грузится на всех путях (кнопка «Отправить тест», конверсионные пуши с постбека, алерты воронки), а не только в кроне дайджестов; на macOS повторная метка уведомления больше не прилетает тихим обновлением без баннера — воркер сначала убирает предыдущее уведомление с той же меткой, у каждого тестового пуша своя метка.
- **Блок аккаунта в мобильном меню**: бургер в узкой или установленной панели открывается пользователем, «Уведомлениями» (→ «Push на телефон»), «Профилем» и «Установить», повторяя меню аватара на десктопе.
- **Маскировка секретов для API-ключей**: `api.php?action=settings` с API-ключом отдаёт каждый секрет как `********` + последние 4 символа; замаскированное значение при отправке обратно не затирает сохранённый секрет.

## Добавления v1.7.5

- **Баннер безопасности PHP («php2shell»)**: панель сверяет работающий интерпретатор с октябрьским адвайзори 2026 (CVE-2026-109618/109619, неаутентифицированный RCE, исправлено в 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35) и показывает красный баннер с командами для конкретной ветки, пока сервер не запатчен; ветки EOL (8.1 и старше) направляются на PHP-апгрейд инсталлятором, дистро-бэкпорты (`apt changelog | grep 109618`) объясняют кнопку закрытия, а обновлятор панели печатает тот же адвайзори после обновления. → [Развёртывание: Обновление PHP](deployment.md)

## Добавления v1.7.7

- **Блок команд в баннере PHP устойчив к вставке**: вставка блока целиком умирала на вопросе apt `Continue? [Y/n]` (следующая строка уходила как ответ, apt отменялся); блок теперь полностью без интерактива — `NEEDRESTART_MODE=a apt install -y --only-upgrade 'php8.X-*'` — где `-y` отвечает на подтверждение, а `NEEDRESTART_MODE=a` на диалог перезапуска сервисов Ubuntu 22.04+.

## Добавления v1.7.6

- **Рабочая команда патча в баннере PHP**: инструкция v1.7.5 `apt upgrade 'php*'` заставляла apt развернуть glob на весь php-раздел архива Ubuntu и упасть на конфликтах, ничего не обновив; баннер, нотис обновлятора и доки теперь печатают `apt install --only-upgrade 'php8.X-*'` (только установленное вашей ветки) и перезапускают php-fpm с nginx, не называя apache2 на серверах без него.

## Добавления v1.8.0

- **Импорт расхода из push/pop сетей**: AdMaven, PropellerAds, Kadam, Galaxion (кампания × зона) и HilltopAds, Adsterra, Clickadu (только кампания) в карточке «Push/Pop сети»; строка зоны относится только к кликам с обоими id — зоны и кампании сети, — а непривязавшийся расход зон суммируется на клики кампании без зоны. → [Push и pop сети](push-pop-networks.md)
- **Zone Killer**: правила на кампании, подсвечивающие — а в режиме auto и блокирующие через API сети — зоны, сжигающие деньги; dry-run по умолчанию, лимит блокировок за проход, журнал только-добавление, Telegram. Блокировка: AdMaven, HilltopAds, PropellerAds, Kadam, Galaxion; Adsterra/Clickadu копируют список для ручного блэклиста. → [Push и pop сети](push-pop-networks.md#zone-killer)

- **Конверсионные попапы**: плагин на уровне кампании (редактор → вкладка «Попап», выключен по умолчанию): попап с кнопкой оффера после задержки и реальной активности; 7 вертикалей × 11 языков, три дизайна, живое превью и подсказка готовности, метрики воронки попапа и измерение «дизайн × текст»; Настройки → Плагины — обзор + шаблон для новых попапов, а `kclient.php` вставляет попап сам. → [Конверсионные попапы](conversion-popups.md)
