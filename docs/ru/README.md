# Документация на русском

Основное дерево `docs/` — на английском: репозиторий публичный, и англоязычные
документы читают все. Эта папка хранит русские версии страниц (снимок на
момент перевода) и внутренние технические спецификации (ТЗ), которые в вики
не публикуются.

Полную и актуальную версию ведите в `docs/` на английском; правки сюда
вносите, только если обновляете русскую копию сознательно.
