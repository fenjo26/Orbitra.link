# Словарь

Сокращения и термины партнёрского маркетинга и арбитража трафика — и что каждый из них значит в Orbitra. Формулы всех колонок отчётов — в [Шпаргалке по метрикам](guide-metrics.md).

## Модели оплаты

| Термин | Расшифровка | Значение |
|---|---|---|
| **CPA** | Cost Per Action | Оплата за целевое действие: лид, продажу, депозит. Самая частая модель в партнёрках |
| **CPL** | Cost Per Lead | Оплата за лид — заполненную форму, номер телефона |
| **CPS** | Cost Per Sale | Оплата за подтверждённую продажу |
| **CPI** | Cost Per Install | Оплата за установку приложения |
| **CPR** | Cost Per Registration | Оплата за регистрацию (гемблинг, дейтинг, финансы) |
| **CPD**, **FTD** | Cost Per Deposit, First Time Deposit | Оплата за первый депозит игрока. «FTD» — и название самого события, «депозит» |
| **BL** | Baseline | Минимальная сумма депозита или ставок, после которой FTD оплачивается |
| **RS**, **RevShare**, ревшара | Revenue Share | Вы получаете процент от того, что игрок или клиент тратит, пока он тратит. В Orbitra приходит постбеками `revshare`, которые добавляются к прибыли, не создавая новой конверсии |
| **Hybrid** | — | CPA + RevShare одновременно |
| **CPC** | Cost Per Click | Оплата за клик — типичная модель цены у источников трафика |
| **CPuC** | Cost Per unique Click | Оплата за уникальный клик |
| **CPM** | Cost Per Mille | Оплата за 1000 показов |
| **CPV** | Cost Per View / Visit | Оплата за визит (поп- и пуш-трафик) |
| **COD** | Cash On Delivery | Оплата курьеру при получении. Типично для нутры и товарки во многих ГЕО; лиды подтверждает колл-центр, поэтому важен апрув |
| **SS** | Self-Service | Противоположность COD: клиент сразу платит онлайн |
| **Payout**, выплата, ставка | — | Сколько партнёрка платит за одну конверсию |
| **Cap**, кап | — | Лимит конверсий в день, который рекламодатель принимает по офферу. Сверх капа конверсии могут не оплатить |
| **Hold**, холд | — | Время, пока конверсия ждёт подтверждения и выплаты. Конверсии «в холде» в Orbitra — это *лиды* |

## Статусы конверсий

| Термин | Значение |
|---|---|
| **Lead**, лид | Конверсия зарегистрирована, но ещё не подтверждена (холд, ожидание) |
| **Sale / Approved**, апрув | Подтверждена и оплачена |
| **Rejected / Declined**, отклон | Отклонена рекламодателем — не оплачивается |
| **Trash**, треш | Невалид: фейковый телефон, дубль, не то ГЕО |
| **Апрув, Approve %** | Доля лидов, ставших продажами |
| **Rebill**, ребилл | Повторный платёж того же клиента (подписки) |

## Метрики эффективности

| Термин | Расшифровка | Значение |
|---|---|---|
| **CR** | Conversion Rate | Конверсии ÷ клики |
| **uCR** | unique Conversion Rate | Регистрации ÷ уникальные клики |
| **CTR** | Click-Through Rate | Клики ÷ показы (для объявления) или клики ÷ просмотры (для лендинга: LP CTR) |
| **EPC** | Earnings Per Click | Доход ÷ клики — сколько стоит один клик |
| **EPV** | Earnings Per Visit | Доход ÷ визиты |
| **eCPC**, **eCPM** | effective CPC / CPM | Реальная цена клика / тысячи, какой бы ни была модель оплаты |
| **ROI** | Return On Investment | (Доход − Расход) ÷ Расход. +100% — вы удвоили деньги |
| **ROAS** | Return On Ad Spend | Доход ÷ Расход. ROAS 2,0 = ROI +100% |
| **Маржа** | Margin | Прибыль ÷ Доход |
| **P/L** | Profit / Loss | Доход − Расход |
| **LTV** | Lifetime Value | Все деньги, которые клиент приносит за всё время (важно для RevShare) |
| **ARPU** | Average Revenue Per User | Доход ÷ пользователи |
| **Уники** | — | Посетители, посчитанные один раз за период — по IP, IP + User-Agent или cookie |

## Трафик и воронка

| Термин | Значение |
|---|---|
| **Арбитраж трафика, медиабаинг** | Покупка трафика и отправка его на офферы с заработком на разнице между расходом и выплатой |
| **Арбитражник, вебмастер, аффилиат, паблишер** | Тот, кто приводит трафик |
| **Рекламодатель (рекл)** | Владелец продукта, который платит за результат |
| **Партнёрка** (CPA-сеть, ПП) | Посредник между рекламодателями и вебмастерами: Dr.Cash, Leadbit, Everad… → [Офферы и партнёрки](guide-offers-networks.md) |
| **Оффер** | Конкретный продукт с условиями (ГЕО, выплата, разрешённый трафик) |
| **Вертикаль** | Категория офферов: нутра (здоровье), гемблинг, беттинг, дейтинг, финансы, крипта, товарка, свипстейки, приложения… |
| **ГЕО** | Страна, на которую льёте. **Tier 1/2/3** — богатые / средние / развивающиеся страны |
| **Источник трафика** | Откуда посетители: Facebook, TikTok, Google, пуш, поп, натив, in-app сети |
| **Пуш, поп, натив, in-page** | Форматы рекламы: уведомления браузера; всплывающие под-окна; объявления, похожие на статьи; баннеры, похожие на пуш, внутри страницы |
| **Воронка** | Путь посетителя: объявление → прелендинг → лендинг → оффер → конверсия |
| **Прелендинг (прокла), лендинг (LP)** | Страница перед оффером, которая прогревает посетителя → [Лендинги](guide-landings.md) |
| **Смартлинк** | Ссылка, которая автоматически подбирает лучший оффер под каждого посетителя |
| **Креатив (крео)** | Само объявление: картинка, видео, текст → [Креативы](guide-creatives.md) |
| **UGC** | User-Generated Content — креативы, будто снятые обычным человеком |
| **Адсет** | Группа объявлений с одной аудиторией и бюджетом (термин Facebook) |
| **Пиксель** | Скрипт рекламной платформы на странице, который сообщает ей о событиях |
| **CAPI** | Conversions API — передача конверсий в Facebook или TikTok «сервер → сервер» вместо пикселя (или вместе с ним) → [Facebook / Meta](facebook.md) |
| **Сплит-тест, A/B-тест** | Показ вариантов равным долям трафика и сравнение результата |
| **Масштабирование** | Увеличение бюджета того, что работает |

## Термины трекера

| Термин | Значение в Orbitra |
|---|---|
| **Трекер** | Программа посередине: маршрутизирует посетителей, считает клики и конверсии — это и есть Orbitra |
| **Кампания** | Трекинговая ссылка со своими правилами → [Первая кампания](guide-first-campaign.md) |
| **Поток** | Правило внутри кампании: фильтры + куда отправлять → [Потоки](guide-streams.md) |
| **Перехватывающий / Обычный / Замыкающий** | Три типа потоков и их приоритет |
| **Ротация** | Распределение трафика между потоками, офферами или лендингами по весам |
| **Click ID, subid** | Уникальный ID клика, который передаётся в партнёрку и возвращается в постбеке |
| **Sub ID, саб, sub1…sub30** | Дополнительные параметры, которые едут вместе с кликом (`sub_id_1`…`sub_id_30`) |
| **Макрос** | Заглушка вроде `{subid}` или `{{ad.id}}`, вместо которой подставляется реальное значение |
| **Постбек, S2S** | Уведомление «сервер → сервер» о конверсии → [Постбеки](guide-postbacks.md) |
| **Токен** | Ключ кампании для интеграционных скриптов и Click API |
| **Click API** | Совместимое с Keitaro API для маршрутизации клика из своего кода (`kclient.php`, `tracking.js`) |
| **Клоакинг (клоака)** | Показ safe page ботам и модераторам и денежной страницы людям → [Клоакинг](guide-cloaking.md) |
| **White page, safe page, «белая»** | Страница, которую видят модераторы |
| **Black page, money page, «чёрная»** | Страница, которую видят живые посетители |
| **Модератор, бот модерации** | Тот, кто проверяет ваше объявление на стороне платформы |
| **Бот** | Автоматический трафик: краулеры, скрипты, сканеры |
| **ASN, ISP** | Сеть и провайдер, которым принадлежит IP посетителя (нужна ASN-база) → [Гео-базы](guide-geo-databases.md) |
| **Трафик из дата-центров** | Визиты с серверов и облаков — почти никогда не живой человек |
| **PWA** | Устанавливаемое веб-приложение → [PWA-приложения](guide-pwa.md) |
| **VAPID** | Ключи, которыми подписываются web-push уведомления → [Пуши](guide-push.md) |
| **In-app браузер, WebView** | Браузер внутри Facebook, Instagram, TikTok, Telegram |
| **MCP** | Model Context Protocol — способ подключить ИИ-ассистента к трекеру → [ИИ-ассистент](guide-mcp.md) |
