# Конверсионные попапы

Попап с кнопкой оффера на ваших лендингах. Попап принадлежит кампании: включается и настраивается на вкладке **Попап** в редакторе (пока включён — рядом с названием вкладки горит точка) и сохраняется обычной кнопкой «Сохранить». Скопированная кампания уносит попап с собой. **Настройки → Плагины** — страница-обзор: у каких кампаний стоит попап и как он работает (шаблон, показы, клики и CTR за 7 дней, кнопка «Настроить» открывает кампанию сразу на вкладке «Попап»), а ниже — **шаблон для новых попапов**, из которого первый раз заполняется попап кампании при включении.

> При обновлении со версии до v1.8.0: общий выключатель убран. Если он был включён, все полагавшиеся на него кампании после обновления получат включённый попап; иначе попап везде останется выключенным.

## Где попап работает

| Где | Как |
|---|---|
| Лендинг, загруженный в Orbitra, или поток «Показать HTML» | Автоматически |
| Внешний сайт с `tracking.js` или `kclient.js` | Автоматически — скрипт читает конфиг попапа из ответа Click API |
| Внешний сайт с `kclient.php` | Автоматически — актуальный `kclient.php` сам дописывает тег попапа, когда у кампании попап включён. Сайтам со **старой копией** файла его нужно один раз обновить; ручная строка `<?php echo $client->popupScript(); ?>` тоже продолжает работать |
| Кампания с прямым редиректом на оффер | Невозможно — нет страницы, где показать попап |

Боты и посетители safe-страницы не видят попап вообще: сервер решает это до того, как отправится хоть байт попап-кода. Кампания только с редиректом может держать попап включённым — её внешний сайт с `tracking.js` законная сцена; вкладка лишь объясняет, где попап сможет появиться.

## Вкладка «Попап»

- Галочка «Показывать попап посетителям этой кампании», под ней — готовность простыми словами: «Готово: попап появится на лендинге этой кампании» или причина, почему попапу негде появиться, с кнопкой «Открыть Интеграции».
- **Живое превью** попапа по мере настройки.
- Четыре шага:
  1. **Шаблон** — одна из семи карточек (Универсальный, Нутра, Казино, Ставки, E-commerce, Финансы, Крипта): задаёт формулировки, сумму по умолчанию и картинку.
  2. **Текст и сумма** — свой заголовок, текст и кнопка; макросы `{amount}`, `{currency}` и `{country}` разрешаются по гео клика. Сумма для бонусных вертикалей задаётся в долларах США и конвертируется в валюту посетителя с «красивым» округлением (250 → 200 € / 7 500 000 ₫); вертикали со скидкой считают её процентом.
  3. **Картинка** — по умолчанию картинка вертикали, или любая из Галереи.
  4. **Когда показывать** — задержка, частота раз в N часов, триггеры глубины скролла и ухода курсора, плюс ждать реальной активности: два *разных* действия, одно из них pointer/touch (движение мыши или тап). Скролл или клавиатура сами по себе не считаются — бот, наученный скроллить, попапа всё равно не увидит.
- **Дополнительно** (свёрнуто): дизайны — Card, Gift (нижний лист), Alert, случайный из включённых на каждый показ; анимация, позиция, цвет акцента, режим языка (авто / принудительный / белый список из 11 встроенных).
- **Сбросить к шаблону** — откатить всё, чего шаблон не просил.

## Кнопка — настоящий шаг воронки

Кнопка попапа — это подписанный переход лендинг → оффер, тот же, что у CTA на лендинге. Нажатие проходит через трекер (`offer_at`, конверсии и метрика CTR попапа ложатся на тот же клик) и несёт `sub_id_30=popup`, чтобы сторона сети отличала попап-трафик.

## Статистика

Доступна с первого дня в настройке колонок отчёта:

| Метрика | Определение |
|---|---|
| **Показы попапа** | Посетители, которым попап реально отрисовался — после задержки и проверки активности, боты исключены |
| **CTR попапа** | Клики попапа ÷ Показы попапа × 100% |
| **Клики попапа** | Нажавшие кнопку оффера |
| **Закрытия попапа** | Закрывшие попап без нажатия |
| **Конверсии попапа** | Конверсии на кликах, пришедших через кнопку попапа |

В конструкторе отчётов также появляется измерение **Вариант попапа** (дизайн × текст) — сгруппируйте по нему, чтобы сравнить варианты. В списке Настроек → Плагины видна короткая версия (показы, клики, CTR) по каждой кампании.
