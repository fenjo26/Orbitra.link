# Конверсионные попапы

Попап с кнопкой оффера на ваших лендингах — **Настройки → Плагины**. По умолчанию выключен: существующая установка не должна внезапно показывать попапы, поэтому до глобального переключателя не появляется ничего. Каждая кампания может переопределить его (редактор кампании, вкладка **Общие** → «Конверсионный попап»: Как в Настройках → Плагины / Вкл / Выкл).

## Где попап работает

| Где | Как |
|---|---|
| Лендинг, загруженный в Orbitra, или поток «Показать HTML» | Автоматически |
| Внешний сайт с `tracking.js` или `kclient.js` | Автоматически — скрипт читает конфиг попапа из ответа Click API |
| Внешний сайт с `kclient.php` | Одна строка перед `</body>`: `<?php echo $client->popupScript(); ?>` |
| Кампания с прямым редиректом на оффер | Невозможно — нет страницы, где показать попап |

Боты и посетители safe-страницы не видят попап вообще: сервер решает это до того, как отправится хоть байт попап-кода. Кампания только с редиректом сохраняет включённый попап намеренно — на её внешнем сайте может стоять `tracking.js`, где попап работает; редактор лишь предупреждает.

## Настройки

- **Вертикаль текста и картинки** — нейтральная (универсальная), нутра, гемблинг, беттинг, e-commerce, финансы, крипта. Задаёт формулировки и картинку по умолчанию.
- **Задержка, частота, глубина скролла** — попап ждёт N секунд (частота: раз на посетителя за N часов, 0 = на каждый просмотр) и может дополнительно требовать доскроллить до доли страницы.
- **Ждать реальной активности** — два *разных* действия, одно из них pointer/touch: движение мыши или тап. Скролл или клавиатура сами по себе не считаются — то же правило, что у подсказки «возможные боты», поэтому бот, наученный скроллить, попапа всё равно не увидит.
- **Exit-intent (десктоп)** — показать, когда курсор уходит через верх окна.
- **Дизайны** — Card, Gift (нижний лист), Alert. На каждый показ выбирается случайный включённый дизайн; отчёты делят конверсии по варианту дизайн × текст, так что видно, что реально конвертит. Анимация, позиция (центр / низ) и цвет акцента общие.
- **Язык** — авто (язык браузера посетителя, 11 встроенных, прочие — английский) или один принудительный; белый список может сузить встроенный набор.
- **Своё число** — для бонусных вертикалей число задаётся в долларах США и конвертируется в валюту посетителя с «красивым» округлением (250 → 200 € / 7 500 000 ₫); для вертикалей со скидкой это процент. Пусто = дефолт вертикали. Свои заголовок / текст / кнопка могут использовать макросы `{amount}`, `{currency}` и `{country}`, которые разрешаются по гео клика.
- **Картинка** — по умолчанию картинка вертикали (в Галерее есть папка «Popup images»); любую картинку из Галереи можно подставить вместо неё.
- **Превью** — примерный вид с первым включённым дизайном.

## Кнопка — настоящий шаг воронки

Кнопка попапа — это подписанный переход лендинг → оффер, тот же, что у CTA на лендинге. Нажатие проходит через трекер (`offer_at`, конверсии и метрика CTR попапа ложатся на тот же клик) и несёт `sub_id_30=popup`, чтобы сторона сети отличала попап-трафик.

## Статистика

Доступна с первого дня в настройке колонок отчёта:

| Метрика | Определение |
|---|---|
| **Показы попапа** | Посетители, которым попап реально отрисовался — после задержки и проверки активности, боты исключены |
| **CTR попапа** | Клики попапа ÷ Показы попапа × 100% |
| **Клики попапа** | Нажавшие кнопку оффера |
| **Закрытия попапа** | Закрывшие попап без нажатия |
| **Конверсии попапа** | Конверсии на кликах, пришедших через кнопку попапа |

В конструкторе отчётов также появляется измерение **Вариант попапа** (дизайн × текст) — сгруппируйте по нему, чтобы сравнить варианты.
