# Чистилка комментариев FB

Скрывает (или удаляет) спам-комментарии под рекламными постами Facebook по расписанию. Пробный режим и действие «скрыть» включены по умолчанию — оба потому, что скрытие обратимо.

## Подключение

- **Токен**: токен пользователя или System User в существующем подключении расхода Facebook. Чистилка берёт токены страниц через `/me/accounts` (кэш на 24 часа) — модерация комментариев работает только токеном страницы. Права: `pages_read_user_content`, `pages_manage_engagement`.
- **Посты**: настраивать нечего. Синк креативов пишет `creative.effective_object_story_id` каждого объявления в `comment_posts` — список постов это побочный продукт синка расхода.
- **Воркер**: `cli/comment_cleaner_cron.php` (install.sh ставит крон на каждые 10 минут). Читает новые комментарии с последней проверки (`filter=stream&order=reverse_chronological&since=…`), применяет набор правил, пишет журнал и пересчитывает расписание поста: новые комментарии сбрасывают задержку, тихие посты проверяются всё реже (15 минут → удвоение, потолок 24 часа), остановленные объявления — раз в сутки.

## Наборы правил

Один набор служит нескольким подключениям FB. Проверки идут в фиксированном порядке — стоп-слова → регулярки админа → ссылки → контакты → только эмодзи → повторы символов → минимальная длина — и **исключения всегда сильнее**: id автора (`id:123`), имя (`name:…`) или фраза. Комментарии самой страницы не трогаются никогда.

- **Стоп-слова** (≤500, по строке) матчатся по *нормализованному* тексту: нижний регистр, кириллические/греческие гомоглифы свернуты в латиницу (`sсаm` с кириллической с всё равно ловится как `scam`), leetspeak декодирован (`fr33 b0nus` → `free bonus`), символы нулевой ширины убраны. Режим «только целые слова» обрамляет границы — «кид» не срабатывает на «кидай мяч» (ловушка, в которую попадает adset.pro).
- **Регулярки** (≤50) доступны только админу — не-админу при сохранении они вырезаются. Каждый паттерн гоняется по входу ≤500 символов с пониженным backtrack-лимитом — это и есть таймаут от катастрофического бэктрекинга.
- **Ссылки** детектятся по *исходному* тексту — `spamlink .com` с пробелом перед точкой всё равно срабатывает, глубокие ссылки мессенджеров (`t.me/…`, `wa.me/…`) считаются ссылками. Белый список доменов покрывает и поддомены.
- **Контакты**: телефоны (7–15 цифр с разделителями), e-mail и приглашения в мессенджеры («DM me», «пиши в лс», …).
- **Только эмодзи**: после снятия эмодзи/пунктуации не остаётся ни букв, ни цифр.
- **Повторы символов**: один и тот же символ 4+ раз подряд.
- **Минимальная длина**: короче N символов.

Пресеты готовы из коробки: «Ссылки и контакты», «Увод в личку», «Скам-обвинения», «Мусор и боты» (словари EN/RU/EL/PT). Кнопка «Проверить текст» показывает, какое именно правило сработает на вставленном комментарии.

Два режима: «только по правилам» (по умолчанию) и «всё, кроме исключений». Отдельный тумблер решает, чистить ли комментарии под выключенными (пауза/удалены) объявлениями.

## Журнал и безопасность

Вкладка «Комментарии» (раздел подключений) показывает каждое действие: время, текст комментария, автора, сработавшее правило, действие, статус — с кнопками **Вернуть / Скрыть / Удалить** по строке. Тексты комментариев живут 60 дней, потом затираются, остаётся только запись о действии.

- **Пробный режим** пишет журнал и не делает на Graph ничего. При выключении панель показывает, сколько комментариев сухой прогон скрыл бы за последние 24 часа.
- **Автопауза**: доля ошибок цикла выше 30% (минимум 10 действий) или код лимита Graph (4, 17, 32, 613) ставит воркер на паузу с баннером и сообщением в Telegram; снятие — одной кнопкой.
- Баннер воркера появляется, когда посты накопились, а крон давно не запускáлся.

## API

`comment_rulesets` (CRUD), `comment_ruleset_test`, `comment_log` (+статистика 24ч), `comment_log_action` (вернуть/скрыть/удалить), `comment_cleaner_status`, `comment_cleaner_resume`.
